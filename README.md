# Sistema de Gestión de Eventos Universitarios

# Descripción
Este proyecto busca facilitar la organización y administración de eventos universitarios mediante un sistema que permita gestionar actividades, inscripciones y asistencia de los participantes.

# Objetivo
Desarrollar un sistema que centralice la información de los eventos universitarios, facilitando su consulta y gestión por parte de participantes, organizadores y administradores.

# Actores

**Participante**: busca eventos, consulta sus detalles y realiza inscripciones.

**Organizador**: crea, modifica, elimina y cancela eventos, consulta estadísticas y registra la asistencia.

**Administrador**: gestiona usuarios, eventos, categorías y consulta estadísticas.

# Funcionalidades principales
**Gestión de eventos universitarios.**

**Inscripción de participantes.**

**Validación de cupos disponibles.**

**Gestión de categorías.**

**Registro de asistencia.**

**Consulta de estadísticas.**

# Herramientas
**Python: lenguaje de programación utilizado para desarrollar la lógica del sistema.**

**Django: framework de Python que permitirá desarrollar la aplicación web y gestionar sus funcionalidades.**

**SQLite: sistema de base de datos para almacenar la información de los usuarios, eventos, categorías, ubicaciones e inscripciones.**

**HTML: utilizado para estructurar las páginas de la aplicación.**

**CSS: utilizado para definir los estilos y la apariencia visual del sistema.**

**Bootstrap: framework CSS que facilitará la creación de una interfaz adaptable y ordenada.**

**GitHub: herramientas para gestionar las versiones del proyecto, compartir el código y coordinar el trabajo entre los integrantes del equipo.**
